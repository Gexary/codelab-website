# Bienvenue sur le site de CodeLab !

CodeLab est un club d'informatique qui forme la nouvelle génération de développeurs en cultivant l'autonomie, la créativité et l'innovation. Nous explorons l'algorithmie, la complexité temporelle, les structures de données et les réseaux pour préparer aux métiers du futur comme le développement, la data science et la cybersécurité. Les membres acquièrent une véritable culture technique : se documenter, utiliser Git/GitHub, résoudre des problèmes et partager leurs connaissances, dans un esprit d'apprentissage collaboratif et d'innovation collective.

## Objectifs

- Améliorer la culture technique de l'équipe
- Développer des compétences en algorithmie, IA, data science et réseaux
- Contribuer à la croissance de l'écosystème de l'informatique

## Compétences

- Connaissance de Git et GitHub
- Connaissance de Python
- Connaissance de JavaScript
- Connaissance de HTML/CSS
- Connaissance de machine learning

## Profil

- Autonomie
- Créativité
- Innovation
